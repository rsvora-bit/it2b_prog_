# Farken's World – HTML Prototype Archive

Tento repozitář obsahuje staré HTML/Three.js prototypy hry Farken's World.

Hra začínala jako single-file HTML projekt inspirovaný survival stylem her jako Rust.  
Jednotlivé verze postupně přidávaly inventář, crafting, stavění, survival systém, loot, furnace, storage boxy, projectile bow, corpse loot a save/load systém.
